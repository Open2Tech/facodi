# Curatorial assessment and manufacturing manifest v1

Five applied production migrations, archived as operational history rather than automatically replayed. The candidate snapshots and assessments reuse analysis_jobs and analysis_job_events; no parallel queue. Evidence hashes bind the assessment to the current candidate, curriculum identity, and content metadata. The report records preliminary editorial judgments, not an independent audiovisual or current syllabus review.

## Manifest contract
`facodi.kf_curation_manufacturing_manifest_v1()` emits one bounded report per eligible unit, only when all current top-five candidates have exact verified source and assessment records. Product KF-CURATION, recipe KF-BOM-CURATION, quantity one. Payload includes ordered job/resource identities, evidence, decisions, source references and next action. Digest is SHA-256 of PostgreSQL JSONB text before adding the digest. Preserve that digest as an opaque identity in Odoo; do not recompute with Python JSON ordering. Re-read current manifest for eligibility. Report scope is curation_report_only, all publication, curricular approval and demand resolution flags are false. A report can document exclusion or insufficient coverage; it does not authorize adding educational links.

Pilot observed: three report packets, six source-verified candidates; three exclusions (Generative AI), two foundational (Plant Biotechnology), one supplementary (Molecular Toxicology). Current syllabus not verified. No new public content or relationships. Tests: exact digest, replay stability, changed source description invalidates whole affected unit packet, a forged publication flag excludes the affected packet, all test changes rolled back. Access is restricted to postgres. Snapshot includes kf_curation_manifest and returned HTTP 200 on 2026-11-28. Existing Odoo receiver does not consume the new field yet.
