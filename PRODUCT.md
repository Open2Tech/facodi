# FACODI

## Users

Learners browsing open educational content; authenticated users maintaining
their accounts; editors preparing courses, curricular units and educational
objects; administrators viewing catalogue counts.

## Purpose

An open digital campus connecting useful learning resources with academic
context. Public discovery does not require an account. No enrolment, progress,
social feed, external synchronization or automated processing in this version.

## Direction

FACODI's open-campus concept is the reference, not its Odoo implementation.
Keep the existing geometric type and lime identity, with readable mixed-case
headings, a light default canvas and clear, compact editorial workflows.

## Principles

- Real catalogue data and honest empty states, never invented content.
- Public discovery first; account and editorial actions clearly separated.
- Explicit errors and status changes, no success-shaped fallbacks.
- RLS enforces data access; frontend roles control navigation only.
- Four aligned languages, keyboard access, visible focus, responsive layouts
  and reduced-motion support.
