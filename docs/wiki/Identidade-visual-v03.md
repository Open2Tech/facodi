# Identidade visual v03

O ponto de partida é o [guia de identidade v03](../facodi-identidade-v03.md). A paleta base combina Paper `#FDFCF7`, Ink `#142846` e Sun `#EFFF00`. Usa Space Grotesk, blocos planos e cantos retos. Escolhe uma ação clara para cada peça.
