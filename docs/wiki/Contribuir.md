# Contribuir para a FACODI

## Sugerir um recurso

Abre [Sugerir recurso](https://facodi.com/suggest), cola o endereço da fonte original e confirma os dados. Indica a unidade curricular quando souberes onde a referência encaixa. Podes acompanhar a decisão na área pessoal, em **As minhas sugestões**.

Para um conjunto já organizado no YouTube, usa o [envio de playlists](https://facodi.com/playlists/submit). Para outras formas de apoiar o projeto, consulta a [comunidade](https://facodi.com/community).

## Trabalhar no repositório

Usa o [README](../../README.md#executar) para preparar o ambiente. Cria uma branch a partir de `facodi`. No pull request, descreve a mudança e os testes feitos. Uma alteração visual deve indicar as páginas e estados verificados, incluindo teclado, telemóvel e os dois temas, quando aplicável.

- [Regras do repositório](../../AGENTS.md) para arquitetura, Bun, visibilidade e testes.
- [Sistema de design](../../DESIGN.md) para componentes, estados e tokens.
- [Regras do catálogo](../CODEBASE.md) para dados, identidade e publicação.
- [Projeto, comunidade e créditos](../facodi-project-identity-community-2026-11-14.md) para papéis, fontes públicas e consentimento.
